
# Doodad Labs

**Open-source, autonomous cyber data aggregation, free for everyone.**

Doodad Labs collects, normalises and publishes cyber security data from across the internet with no human intervention. Its modular architecture runs each data source as an independent component, so sources can be added, fixed or retired without touching the rest of the platform.

It's built for anyone, from solo researchers and students to SOC teams and large organisations. The data is free to use, with little to no limits.
